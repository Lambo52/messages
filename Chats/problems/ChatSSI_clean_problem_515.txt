Il problema principale riguarda l'elevato utilizzo della CPU causato da query lente dopo l'aggiornamento delle statistiche Oracle effettuato da @Support Technician 21. Questo ha portato a problemi di esecuzione delle query da parte di Access e SQL Developer. La causa sembra essere l'accumulo di dati non necessari in alcune tabelle (come protocolli e tracce di dati non utili dopo 3 mesi), che hanno reso le tabelle molto grandi. Adrian Cindea ha spiegato che è stato necessario modificare il piano di esecuzione di Oracle per ripristinare il sistema a una situazione normale. La risoluzione proposta include la gestione dei dati storici o l'eliminazione di tabelle grandi con dati non importanti. Benedetta Zini ha chiesto se fosse possibile aggiornare le statistiche Oracle regolarmente (ogni giorno, settimana o due settimane) per prevenire il problema senza eliminare dati o tabelle.
